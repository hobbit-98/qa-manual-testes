# Automation Exercise

## Objetivo

Este projeto reúne casos de teste manuais desenvolvidos para o site Automation Exercise.

O objetivo foi praticar técnicas de Quality Assurance, documentação de testes e validação funcional de uma aplicação web.

---

## Escopo dos testes

As funcionalidades validadas neste projeto incluem:

- Cadastro de usuário
- Login
- Logout
- Validação de mensagens do sistema
- Cadastro com e-mail já existente
  
---

## Tecnologias e Ferramentas

- Microsoft Excel — documentação dos casos de teste.
- Google Chrome — execução dos testes manuais.
- GitHub — versionamento e publicação do portfólio.
