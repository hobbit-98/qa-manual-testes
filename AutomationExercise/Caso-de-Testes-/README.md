# Casos de Teste

Este diretório reúne os casos de teste manuais desenvolvidos para o projeto Automation Exercise, documentando os principais fluxos funcionais da aplicação.

## Test Cases

| ID | Cenário | Status |
|----|----------|--------|
| [TC01](./TC01_Register_User.pdf) | Cadastro de novo usuário | ✅ |
| [TC02](./TC02_Login_Valid_User.pdf) | Login com credenciais válidas | ✅ |
| [TC03](./TC03_Login_Invalid_Password.pdf) | Login com senha inválida | ✅ |
| [TC04](./TC04_Logout_User.pdf) | Logout do usuário | ✅ |
| [TC05](./TC05_Register_Existing_Email.pdf) | Cadastro com e-mail já existente | ✅ |

## Objetivo

Este conjunto de casos de teste foi desenvolvido para validar os principais fluxos funcionais da aplicação, garantindo que os requisitos atendam ao comportamento esperado.

Cada caso de teste documenta:

- Pré-condições
- Passos de execução
- Resultado esperado
- Resultado obtido
- Evidências
