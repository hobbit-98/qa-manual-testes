# Casos de Teste

Este diretório reúne os casos de teste manuais desenvolvidos para o projeto Automation Exercise, documentando os principais fluxos funcionais da aplicação.

## Test Cases

| ID | Cenário | Status |
|----|---------|--------|
| TC01 | Cadastro de novo usuário | ✅ |
| TC02 | Login com credenciais válidas | ✅ |
| TC03 | Login com senha inválida | ✅ |
| TC04 | Logout do usuário | ✅ |
| TC05 | Cadastro com e-mail já existente | ✅ |

## Objetivo

Este conjunto de casos de teste foi desenvolvido para validar os principais fluxos funcionais da aplicação, garantindo que os requisitos atendam ao comportamento esperado.

Cada caso de teste documenta:

- Pré-condições
- Passos de execução
- Resultado esperado
- Resultado obtido
- Evidências
